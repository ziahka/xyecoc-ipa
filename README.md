# Xyecoc Mail для iOS

Нативный, быстрый и безопасный клиент для почты **Xyecoc Mail**, созданный специально для iPhone. 

Приложение работает напрямую с серверами `xyecoc.com` без сторонних прокси-серверов и посредников. Все данные, токены и пароли хранятся исключительно на вашем устройстве в защищенном хранилище iOS (Keychain).

---

## Возможности

* **Мультиаккаунт:** Подключение и мгновенное переключение между несколькими почтовыми ящиками (до 15 аккаунтов).
* **Полноценная работа с почтой:** Просмотр входящих, сортировка по папкам и тегам, быстрый поиск и свайп-действия (удаление, отметка прочитанным, избранное).
* **Создание и отправка писем:** Удобный редактор, ответы, пересылка и прикрепление любых вложений (фотографии, документы, файлы).
* **Чтение HTML-писем:** Корректное отображение форматирования, картинок и стилей.
* **Офлайн-режим:** Доступ к ранее загруженным письмам даже без подключения к интернету.
* **Безопасность:** Поддержка двухфакторной аутентификации (2FA) и шифрование данных на уровне системы.

## Как скачать и установить на iPhone

Для установки приложения не нужен App Store. Готовый установочный файл (`.ipa`) собирается автоматически в облаке и устанавливается на телефон с помощью вашего Apple ID.

### Шаг 1. Скачайте файл приложения (.ipa)

1. Перейдите во вкладку **Actions** в этом репозитории.
2. Откройте последний успешный запуск (с зеленой галочкой).
3. В блоке **Artifacts** внизу страницы нажмите на **`XyecocMail-unsigned`** и скачайте архив.
4. Распакуйте архив на компьютере — внутри будет установочный файл `XyecocMail-unsigned.ipa`.

---

### Шаг 2. Установите приложение на телефон

Выберите один из двух простых способов установки:

#### Способ А: Через Sideloadly (Простая установка через провод)
*Подходит для Windows и macOS.*

1. Скачайте и установите программу [Sideloadly](https://sideloadly.io/) на компьютер.
2. Подключите iPhone к компьютеру через кабель. Если телефон спросит «Доверять этому компьютеру?» — нажмите **Доверять**.
3. Запустите Sideloadly и перетащите файл `XyecocMail-unsigned.ipa` в окно программы.
4. В поле **Apple ID** введите почту вашей учетной записи Apple.
5. Нажмите кнопку **Start** и дождитесь завершения установки.

#### Способ Б: Через AltStore (Установка и автообновление по Wi-Fi)
*Подходит, если вы хотите обновлять приложение без подключения проводом.*

1. Установите **AltServer** на компьютер с официального сайта [altstore.io](https://altstore.io/).
2. Подключите телефон проводом и установите приложение **AltStore** на iPhone через меню AltServer на компьютере.
3. Отправьте файл `XyecocMail-unsigned.ipa` на телефон (через AirDrop, Telegram «Избранное» или iCloud Drive).
4. Откройте приложение **AltStore** на iPhone, перейдите во вкладку **My Apps**, нажмите **«+»** в левом верхнем углу и выберите скачанный `.ipa`.

---

### Шаг 3. Первый запуск на iPhone

После первой установки iOS заблокирует запуск приложения от неизвестного разработчика. Это стандартная защита системы.

1. Откройте на телефоне **Настройки** → **Основные** → **VPN и управление устройством**.
2. В блоке «ПО разработчика» нажмите на строку с вашим Apple ID.
3. Нажмите кнопку **«Доверять [ваш Apple ID]»** и подтвердите действие.
4. Запустите **Xyecoc Mail** с экрана «Домой» и войдите в свой почтовый ящик.

## Важная информация об ограничениях iOS

При бесплатной установке приложений в обход App Store действуют системные правила Apple:

* **Переподпись раз в 7 дней:** Бесплатный сертификат разработчика действует 7 дней. По истечении этого срока приложение перестанет открываться. Чтобы продолжить пользоваться почтой, просто переустановите `.ipa` через Sideloadly заново или настройте автообновление в AltStore по домашней сети Wi-Fi. Все ваши письма и настройки при этом сохранятся.
* **Лимит приложений:** На один бесплатный Apple ID можно установить не более 3 сторонних приложений одновременно.
* **Уведомления:** В связи с политикой безопасности Apple, фоновые Push-уведомления для неподписанных приложений работают только при открытом приложении или периодическом фоновом обновлении iOS.
